## О проекте

Встраиваемая конфигурация 1С 8 "Универсальные механизмы" редакция 3. Конфигурация предназначена для использования на платформе 1С Предприятие 8 на версии 8.3.27 и старше. Интерфейс конфигурации поддерживает режим "Такси" и режим интерфейса 8.5. 

В состав конфигурации входят 2 подсистемы:
- Многопоточный конвейер. Позволяет быстро организовать многопоточную, отказоустойчивую обработку произвольных данных.
- Константы. Позволяет организовать удобное ретроспективное хранение констант.

Порядок встраивания конфигурации описан в документации проекта по ссылке https://github.com/ASZykov/1c-um/wiki
